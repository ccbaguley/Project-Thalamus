# Project Thalamus
**Sovereign Neuro-Physical, Trauma-Informed & Elvish Sanctuary Engine**

An offline-first, zero-persistence Ubuntu & Python architecture designed for trauma recovery, boundary discernment, and emotional equilibrium without coercion or telemetry.

## Core Guarantees
* **Zero Behavior Modification:** Acts as a non-coercive mathematical mirror.
* **RAM-Only Sanctuary:** Operates strictly in volatile memory with no disk logging.
* **Zero Dependencies:** Built exclusively using Python 3.8+ standard library (`hashlib`, `math`, `os`, `sys`, `time`).

* `thalamus_os.py` — Self-contained, single-file RAM sanctuary CLI entrypoint.
* `thalamus_core/` — Modular 12-pillar library (`neuro_math`, `lenz_alchemy`, `trauma_sanctuary`, `mbti_telemetry`, `elvish_mesh`, `mithril_guard`, `darvo_shield`, `shaolin_forge`, `neuro_plasticity`, `reticular_lockout`, `natural_mirror`, `compassion_gate`).
